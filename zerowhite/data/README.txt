optdigits_uci_sample.csv.gz
  1,797 real handwritten-digit samples (8x8 pixels, values 0-16, last column = label 0-9):
  the UCI "Optical Recognition of Handwritten Digits" test set
  (E. Alpaydin & C. Kaynak, Bogazici University; UCI Machine Learning Repository, CC BY 4.0).
  Shipped so the `digits` task works fully offline. When the full UCI archive is
  reachable, `python3 app.py data fetch digits` downloads the complete 5,620-sample set.
